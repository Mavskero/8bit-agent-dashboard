桌宠动画 v3：六组，512×512，真实透明背景，无损 WebP，无限循环。

打字：6 帧，双手手指轮流敲击键盘，仅第 4 帧闭眼，眨眼按帧数和时长均占 16.7%。思考：10 帧，人物固定注视电脑，脸颊侧依次出现由小到大的两个气泡和一个灯泡，灯泡点亮后反向淡出。完成 OK：19 帧，从打字基准帧起手，细化抬手、转腕、OK 和指尖星光，再收手。品茶：12 帧，闭眼品尝停留约 1 秒，人物、杯子、电脑逐像素静止，仅独立香气图层随风变化；完整动作约 3.14 秒。

全部动作以笔记本盖板为固定锚点校准，保留敲键盘、抬手、扶额、品茶等有意义的动作。打字与思考逐帧复用同一人物主体，只有手指、闭眼和灵感图层变化；完成动作的首尾帧也使用同一基准，避免状态切换时躯干位移。应用显示时使用高质量透明插值生成平滑过渡。`manifest.json` 记录每帧时长、校准方式和边缘处理结果。

所有新增人物和特效图像由内置 imagegen 生成，`generation.json` 保存最终提示词；脚本负责拆帧、透明通道、动画图层合成和固定锚点校准。

应用运行时优先读取 `Frames/<action>/` 中的完整透明 PNG 帧，并使用 `manifest.json` 的逐帧时长。WebP 作为紧凑备份保留，不参与内置动作的正常播放，从而避免增量帧 disposal/blend 在动作切换时留下边缘残影。
