# Runtime Status icons

Shared extraction specification: isolate exactly one requested symbol; faithfully reconstruct it as sparse 8-bit pixel line art with hard square pixels, the same limited palette and line weight; center one icon on a square canvas with generous genuinely transparent padding; omit the dark panel, glow, shadow, extra icons, text, and watermark.

2. Thinking: second purple head profile with small gear.
3. Fast mode: third cyan lightning bolt.
4. Provider: fourth cyan wireframe globe.
5. Legacy balance: fifth olive-green dollar sign.
6. Tokens: sixth purple circular badge / coin with inner V-shaped mark.
